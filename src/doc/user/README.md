# 📋 用户手册：通过控制器连接设备

------

## 🖥️ 第一步：配置网络连接

### 1.1 直连设备

- **方式**：使用网线**直接连接控制器和笔记本电脑**
- **要求**：确保电脑的 IP 地址设置为 **192.168.1.100**（局域网方式）

### 1.2 使用路由器连接

- **方式**：通过**路由器连接设备**

- 操作

  1. 登录路由器管理界面。
  2. 查看并记录控制器设备的 IP 地址。
  3. 使用该 IP 地址进行后续操作。

------

## 🔌 第二步：登录设备控制界面

### 2.1 通过路由器连接

- **IP 地址**：使用路由器获取到的控制器 IP 地址

- **端口**：**80**

- 浏览器访问


  ```
  http://<设备IP>:80
  ```

- **功能**：进入 **运动控制界面**，进行设备调试与控制。

### 2.2 局域网连接（固定 IP）

- **IP 地址**：192.168.1.109

- **端口**：**80**

- 浏览器访问

  ```
  http://192.168.1.109:80
  ```

- **功能**：进入 **运动控制界面**，进行设备调试与控制。

------

## 🌐 第三步：登录 Node-RED 编程界面

- **端口**：**1880**

- 浏览器访问

  ```
  http://<设备IP>:1880
  ```

- **功能**：进入 **Node-RED 编程界面**，实现自动化逻辑与流程控制。

## ❗ 注意事项

- 确保网络连接正常，IP 地址配置正确。
- 使用浏览器访问时，请使用**Chrome / Edge / Firefox** 等现代浏览器。
- 若无法访问，请检查防火墙或设备是否启用对应端口。
